## 验证范围

无需底座的 smoke 使用合成向量和小型预测器。短程 Gate 1 需要实际底座与 JSONL，用于验证训练链路。正式复现还要求固定输入、独立留出集、相同检查点上的各项指标及完整的报告证据。三种验证覆盖不同问题，结果分开记录。
